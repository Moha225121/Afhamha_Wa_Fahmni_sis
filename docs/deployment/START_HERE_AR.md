# ابدأ من هنا — تسليم مدرسة النسبية

الهدف تطبيق **مدرسة النسبية في جذر المستودع**. لا يشمل مجلد المدرسة الأخرى. هذه حزمة مصدر كاملة قابلة لإعادة البناء، وليست فرق ملفات ولا نسخة vendor/node_modules من Windows.

حالة الإقفال: **HANDOFF_READY / PRODUCTION_NO_GO**. نجح تثبيت الاعتمادات المقفلة وبناء النسخة المفكوكة واختبارها محليًا على SQLite وPostgreSQL17.11، وفحوص المتصفح والترقية والاستعادة. بقيت اختبارات الاستضافة والأجهزة والمزود الفعلي محددة بمالك ودليل في الوثائق. القرار وأسبابه في `RELEASE_READINESS.md`، ومعرف المصدر والأدلة في `TEST_EVIDENCE.md` وmanifest؛ جاهزية التسليم لا تمنح إذن نشر.

ترتيب القراءة:

1. `RELEASE_READINESS.md`: قرار تسليم الحزمة منفصلًا عن اعتماد الإنتاج والقيود المتبقية.
2. `DIGITALOCEAN_HANDOFF_AR.md`: المرجع التنفيذي الوحيد للأوامر والإعدادات والترقية والخدمات والرجوع. مطابق لنسخته داخل `source/docs/deployment`.
3. `ENV_CHANGES.example`: متغير العرض الجديد فقط؛ لا تستبدل به `.env` الحقيقي.
4. `QA_CLOSEOUT_AR.md` و`TEST_EVIDENCE.md`: جميع البنود وأسبابها ومستوى تحقق كل دليل؛ سجل التفاصيل داخل `source/docs/qa`.
5. `DEVICE_STAGING_ACCEPTANCE_AR.md`: العمل المتبقي لمسؤول الاستضافة وفريق QA ومالك اعتماد المزود، مع حقول نتائج فعلية غير مؤشرة لما لم ينفذ.
6. `RELEASE_MANIFEST.json` و`SHA256SUMS.txt` وبصمة ZIP الجانبية: تحقق من اكتمال الملفات وتطابقها قبل تثبيت الاعتمادات.
7. `MESSAGE_TO_HOSTING_AR.txt`: رسالة جاهزة يمكن للمستخدم إرسالها؛ لم تُرسل آليًا لأي شخص.

مجلد `source/` يحتوي الشيفرة وملفات القفل والأصول العامة الأصلية والاختبارات وملفي migration في مساراتهما الأصلية. الاعتمادات والأصول المجمعة **غير مرفقة**؛ تثبت الاعتمادات من القفل وتُبنى أصول Vite في البيئة المستقبلة بقيم Firebase العامة المعتمدة. لا تنسخ وحدات Windows الأصلية إلى Linux.

ملفات المثال وبيانات الاختبارات اصطناعية، ولا توجد بيانات مدرسة أو حساب خدمة أو `.env` أو قاعدة/نسخة احتياطية أو رفع خاص أو جلسات أو سجلات ضمن الحزمة. مجلدات storage فارغة عدا ملفات حفظ البنية. الملفات الداخلية للبصمات تستثني نفسها والأرشيف لتجنب الدائرة الذاتية؛ البصمات أدوات سلامة وليست توقيعًا موثوقًا.

لا تشغل سكربتات التثبيت التاريخية أو composer setup، ولا تنفذ migration أو نشرًا أو تجربة إرسال على الإنتاج قبل تأكيد البيئة والنسخة الاحتياطية واختبار الاستعادة والموافقة المنفصلة. فك الضغط وتثبيت الاعتمادات بالطريقة الموثقة لا ينفذان migrations تلقائيًا.
