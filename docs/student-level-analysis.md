# تحليل مستوى الطالب

تتوفر صفحة «تحليل مستوى الطالب وخطة الدعم بالذكاء الاصطناعي» من ملف الطالب لدى الإدارة والمعلم، ومن ملف الابن في بوابة ولي الأمر. يضغط المستخدم «إنشاء التحليل وخطة الدعم» ثم تظهر القراءة التربوية والخطة الأسبوعية ومؤشرات المتابعة وحدود البيانات.

تستخدم الميزة اتصال Gemini نفسه الموجود في إعدادات Smart Tutor. لا تحتاج إلى ترحيل جديد لقاعدة البيانات.

## البيانات والصلاحيات

- آخر 90 يومًا، وبحد أقصى 100 نتيجة منشورة. تستخدم قواعد نشر النتائج الحالية، بما فيها النتائج المرحلية والاختبارات القديمة المسموح بعرضها، لتجنب احتساب النتيجة نفسها مرتين.
- المتوسط هو متوسط النسب الصحيحة للنتائج المتاحة، وليس المعدل الرسمي.
- الحضور يشمل الحاضر والمتأخر والمتأخر بعذر؛ الأيام غير المسجلة لا تدخل في المقام.
- متابعة تسليم الواجبات المنشورة التي انقضى موعدها في الفترة.
- كشوف المعلم الحديثة تظهر للإدارة والمعلم كملخصات منفصلة ولا ترسل لولي الأمر ولا تدمج مع المتوسط المنشور.
- المعلم يرى الطلاب في صفوفه ونتائج مواده المسندة فقط. ولي الأمر يرى أبناءه المرتبطين فقط. يعاد فحص الصلاحيات عند كل طلب.
- لا ترسل أسماء الطلاب أو أرقامهم أو بيانات الاتصال أو الملاحظات الخاصة إلى Gemini. يحتوي الطلب على مؤشرات الأداء وأسماء المواد والمرحلة التعليمية.

## التوليد

طلب POST محمي بـ CSRF ومحدد بستة طلبات في الدقيقة. لا يؤدي فتح الصفحة إلى استدعاء Gemini. تحفظ النتيجة في التخزين المؤقت ست ساعات لكل مستخدم وطالب ونطاق وبصمة بيانات؛ تتوقف مطابقة التقرير السابق عند تغير المدخلات، بما فيها إخفاء نتيجة منشورة. يمنع القفل تكرار الاستدعاءات المتزامنة. النص معروض بترميز HTML الآمن.

خطة ولي الأمر تتضمن أنشطة منزلية قصيرة ومتابعة أسبوعية وأسئلة للمعلم. لا يفترض النظام أن نقص البيانات يعني تدني المستوى، وتوضح الصفحة أن التحليل مساعد ويحتاج إلى مراجعة المعلم.

## التحقق

```sh
php artisan test --filter='StudentLevelAnalysisTest|ResultPublicationTest|ParentPortalTest|GeminiSmartTutorGatewayTest'
```

يمكن استخدام `DB_CONNECTION=sqlite` و`DB_DATABASE=:memory:` لتشغيل الاختبارات المعزولة عند غياب PostgreSQL المحلي.
