## حماية المسارات الناجحة والرفع

أُعيد فحص تسليم الملف والتصحيح وإشعارات الطالب/الولي الواردة كنجاحات في F، وفتح رسائل الولي ودخول الطالب وجدولة الاختبار وإنشاء الواجب وإرسال إشعار المعلم وإتاحة الامتحان. البنود T6/7/18/19/22 المتناقضة تبقى «لم يُعَد إنتاج الخطأ التاريخي» حتى مع PASS للرحلة الحالية؛ T20 سليمة في الجدول وفاشلة بالتفصيل، ولم يُنسب إليها سبب غير مثبت.

اختبار I إضافي مرتبط بقبول الرفع، لا ادعاء أن صورة T3 أثبتته: النموذج يحتفظ بالملفات والنص عند فشل النقل، ويعيد **الطلب الكامل نفسه**. رمز إنشاء الدرس القائم يمنع تكراره، وجدول إيصالات تحديث جديد يمنع تكرار مرفقات التعديل. عند نتيجة شبكة ملتبسة يُثبّت payload حتى تأكيد الحفظ؛ أخطاء validation تعيد إتاحة التصحيح. تُجدد CSRF بعد انتهاء الجلسة دون reload. فشل مؤكد قبل commit يتراجع عن الحفظ وينظف الملفات الجديدة غير المرجعية فقط؛ نتيجة commit المجهولة تحتفظ بالملفات، والنجاح بعد استثناء يتطلب التحقق من سجل الحفظ المطابق. أُثبت ذلك بحقن فشل قبل commit وبعده في الإنشاء والتعديل.

PASS في Edge: رفع PNG وMP4 مولّد اصطناعيًا، قطع قبل وصول الطلب، ثم فقد الرد بعد commit، ثم retry؛ درس واحد ومرفقان فقط. تكرر السيناريو لتعديل الدرس دون مرفق مكرر. نُزلت بايتات الملفين المخولين وطابقت الأصل، وشغّل decoder المتصفح MP4. لا استكمال بايتات جزئي، ولا كاميرا فعلية، ولا تعميم دعم أجهزة.

بيئة الاختبار: Windows، PHP 8.4.21، PostgreSQL 17.11 حقيقي وSQLite معزول، Edge Chromium 157.0.4341.42. عرض 390/1440 CSS px محاكاة شاشة، وليس iPhone/Safari حقيقيًا. النموذج منفصل عن `.env` وuploads الفعلية؛ HTTP الخارجي والبريد والإشعارات الحية ممنوعة. فحوص PWA السابقة أُعيدت في fixture SQLite مستقلة؛ رحلات الجولة والتعليم والإدارة والمساعد استعملت PostgreSQL المعزول. اختبار ترقية PWA يستعمل worker تاريخيًا موثقًا مع icon shim للاختبار، ولا يثبت تطابق الحزمة التاريخية أو ترقية هاتف فعلي. تحذيرا الحزمتين الاختياريتين `fontaine` و`@napi-rs/canvas` لا يمنعان البناء/قراءة PDF المختبرة؛ لا أضيفت اعتمادات لإخفائهما.

فحص الترقية: من 44 migration في commit البداية إلى 46؛ 22/22، وبصمات 76 جدولًا و179 صفًا اصطناعيًا متساوية بعد pg_dump/pg_restore. بقيت إجابات/درجات/رسائل/دفعة جزئية وملفات مرفوعة دون تغير. لا backfill مصطنع للأحداث والإيصالات؛ إعادة migrate لا تغيّر البيانات؛ rollback يلغي نفسه عند وجود تاريخ إلغاء. هذا لا يقيس زمن أقفال بيانات المدرسة أو Linux.

البناء من القفل والأصول نجح محليًا؛ لا اعتماد أو تغيير lockfile جديد. وَحَّدنا مسار اختبارات JavaScript إلى `tests/js` ليشمل الأمر نفسه كل الملفات على Linux حساس حالة الأحرف. لا CI مُعد في المستودع، ولذلك **CI VERIFIED = NOT CONFIGURED**، وليس PASS مختلقًا.

## التسليم والمتبقي

حالات التسليم منفصلة: IMPLEMENTED؛ TESTED LOCALLY وفق الأدلة النهائية؛ CI VERIFIED وفق أعلاه؛ MERGED INTO MAIN وفق PR/التحقق النهائي؛ **MANUAL DEPLOYMENT PENDING**؛ **PRODUCTION ACCEPTANCE PENDING**.

لا عيب برمجي معروف متروك في نطاق الإصلاحات المقبولة عند الإقفال. القبول الحي لـPush/Gemini والأجهزة وتهيئة المحتوى ومطابقة Linux/الاستضافة يبقى غير منفذ؛ لا يتحول إلى نجاح من اختبارات mock. لا سياسة إلغاء مالي تاريخي جديدة، ولا إصلاح صفوف إنتاج مشتبهة دون جرد ومراجعة قابلة للرجوع. لا يُدعى أن الموقع الحي حُدث.
