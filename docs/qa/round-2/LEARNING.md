كشف اختبار المتصفح عيبين مرتبطين لم تكن فحوص HTTP وحدها تكشفهما: خانة ملاحظة الطالب كانت `input type=text` فتحول الملاحظة متعددة الأسطر إلى سطر واحد، فأصبحت `textarea` بحد 2000 حرف مطابق للخادم. وكان فتح تعديل سؤال صح/خطأ يعيد الإجابة الصحيحة المحفوظة «خطأ» إلى «صحيح»؛ أصبح المحرر يحفظ الاختيار القائم. أُعيد إنتاج العيبين قبل الإصلاح ثم نجح المساران الفعليان: ملاحظة عربية بسطرين بعد إعادة التحميل والتصحيح، واختيار «خطأ» بعد حفظ الاختبار وإعادة فتحه ثم إجابة الطالب وتصحيحها ونشر نتيجة 90%.

عُزز استيراد النتائج بقفل صفوف الاختبارات بترتيب ID ثابت قبل قراءة ارتباط الفترة؛ يمنع ذلك تنافس فترتين على الاختبار نفسه، مع الإبقاء على ترتيب معالجة الاختبارات وسياسة استبدال درجة المادة القائمة. رفض ارتباط فترة أخرى يعيد الدفعة كاملة دون علامات أو روابط جزئية. سجل إلغاء/حذف الاختبار يحمل ID الامتحان ولقطة قيمه السابقة، وليس حدثًا بلا هوية.

## هوية النتائج والتعامل مع تكرار تاريخي مزعوم

لا تغيير للـunique constraint القائم. `grades` هو `(exam_id,student_id)`، والمحاولات تحتفظ بـ`attempt_number` منفصلًا. `result_marks` إسقاط رسمي لمادة واحدة داخل فترة محددة؛ واجهة الاستيراد السابقة تصرح بأن الاستيراد يستبدل درجة المادة الحالية. اختلاف نوع الامتحان يتطلب فترة مختلفة وفق هذا النموذج، ولا تُجمع درجات عدة امتحانات اعتباطيًا. كشوف المعلم الحالية خاصة بالمعلم/الصف، ويختار المسؤول مادة مخوّلة عند الاستيراد؛ لا يوجد عمود subject_id في grade_sheets ولا نفترضه.

لم تُفحص قاعدة الإنتاج ولم تُحذف «مكررات» استنادًا إلى أسماء المواد. إذا ظهرت صفوف مشتبهة بعد النشر: يصدر المسؤول قراءة منقحة لـIDs الفترة/السنة/نوع الامتحان/المادة/الطالب/المصدر؛ تُقارن الهوية الفعلية وأثر audit، ويُراجع كل ترابط وإشعار قبل خطة تصحيح قابلة للرجوع. تشابه اسم مادتين ليس مبررًا لدمجهما أو حذف درجاتهما. الحذف الجديد يخص درجة مسودة مختارة صراحة فقط، ويحتفظ بدرجة الامتحان والمحاولة الأصلية.

## الأوامر والحدود

قبل الإصلاح فشل `Round2LearningTest` بست حالات من ست على نسخة البداية؛ شمل ذلك 500 مثبتًا عند حذف امتحان له إجابات، وفقد الملاحظة في عرض التصحيح، وظهور HTML حرفيًا، وغياب كود المادة في محددات مرتبطة. الأدلة الخام المحلية تحت `tmp/qa-round-2` ولا تُلتزم لأنها تتضمن HTML اختبار كاملًا.

فحص النطاق الموسع بعد الإصلاحات الأساسية: PASS، **167 اختبارًا، 1232 تأكيدًا، 27.554 ثانية**. بعد إصلاحات المتصفح وتعزيز قفل الاستيراد والتدقيق، أُعيد فحص `ResultPublicationTest` و`Round2LearningTest`: **18 اختبارًا، 261 تأكيدًا، 6.259 ثانية، PASS**. نتيجة المجموعة الكاملة على النسخة النهائية في تقرير القبول الجامع؛ لا تُجمع الأعداد المتداخلة.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/qa/run-isolated.ps1 tests/Feature/Round2LearningTest.php tests/Feature/ResultPublicationTest.php tests/Feature/QaLearningAcceptanceTest.php tests/Feature/TeacherHighSeverityFixTest.php tests/Feature/TeacherPortalWorkflowTest.php tests/Feature/AssignmentContentTest.php tests/Feature/StudentAcademicPortalTest.php tests/Feature/TeacherGradeSheetPercentageTest.php tests/Feature/DemoPortalSmokeTest.php tests/Feature/PublicLoginTest.php
```

البيئة: Windows/PHP المحلي، SQLite `:memory:` مع storage منفصل، `.env` معطّل، HTTP خارجي ممنوع. لا migrations تخص هذا المسار. صيغة جدولة النتائج الحالية مصرح بها في النموذج **UTC**؛ اختُبر حفظ `2027-01-01T00:30` وتوقف النشر عند `00:29:59 UTC` ونشره عند الحد `00:30:00 UTC` مرة واحدة. لا تحويل بساعتين ولا تغيير عالمي للوقت.

نُفذ متصفح learning فعليًا: **6/6 PASS**، والملاحظة العربية متعددة الأسطر ظاهرة بجانب الملف بعد reload، مع تنزيل الملف وتصحيح الدرجة ونشرها للطالب والولي. نُفذ academics فعليًا: **9/9 PASS**، إدخال محرر غني بالأسطر والعربية والعبارة الحرفية `2 < 5 & 7 > 3`، ثم عرض الطالب وتصحيح المعلم بلا وسوم أو كيانات ظاهرة، وحفظ إجابة صح/خطأ «خطأ»، حتى اعتماد النتيجة ونشرها. لا أخطاء JavaScript غير معالجة ولا HTTP 5xx في المسارين. البيئة: Windows، Edge **157.0.4341.42**، viewport **390×900**، loopback ببيانات اصطناعية وحجب طلبات الخارج وService Workers. الأدلة المنقحة في `evidence/learning/browser-learning.json` و`browser-academics.json` وصورهما؛ روجعت بصريًا صورة الملاحظة بعد تمرير الجدول أفقيًا وصورة سؤال الاختبار. كلا السكربتين يقبل `QA_EVIDENCE_DIR` لعزل أدلة الجولة.

التسليم يدوي لموظف الاستضافة. لا اختبار إنتاج، لا Push لجهاز فعلي، لا Gemini حي، لا ادعاء توافق شامل للهواتف. تبقى حماية attempts/answers/grades وpermissions والمراجعة الإدارية مطلوبة بعد النشر.
