## النشر وحدود البيانات

لا migration أو dependency جديدة لهذه الدفعة. تُنشر PHP/Blade والمسارات معًا، ثم يُعاد route/view/config cache بحسب دليل الاستضافة المعتمد، دون استبدال `.env` أو storage أو قاعدة البيانات. FK introspection يستخدم API Laravel المخزّن، ويمر على العلاقات الحقيقية بما فيها soft-deleted rows؛ لا حذف pivots أو تعطيل FK لتجاوز الحماية. لا repair أو deduplication لبيانات الإنتاج.

تعطيل تعريف رسوم لا يلغي التزامًا. الإعفاء أو التصحيح المالي يستخدم الآلية المعتمدة الموجودة مع السبب والتدقيق؛ إلغاء تاريخي جماعي/رد دفعات يحتاج سياسة منفصلة، ولم يُنفذ أو يُفترض. صور الطلاب الجديدة تبقى في storage الدائم. إعادة الكود لا تستلزم حذف أي صورة/رسالة/درجة/دفعة جديدة.

بعد النشر اليدوي، باستخدام حسابات اختبار معتمدة: تحقق من صورة محفوظة بعد reload وبطاقة عربية، بحث المعلمين/الأولياء، الأحد والشعبة والاستراحة، مكتبة بكتاب مؤهل، modal المشرفين وحفظ التكليف، إيقاف حساب مرجعي مع بقاء تاريخه، أرشفة وإعادة فتح محادثة، حذف تعريف رسوم غير مستخدم فقط، ومطابقة مجموع الحساب المحدد مع كشفه. لا حذف سجلات أسر حقيقية بغرض الاختبار.
